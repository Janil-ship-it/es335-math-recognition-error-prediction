## Research question

At the same human review budget (20%, 30%, 50% of lines), does a learned flagger catch more wrong recogniser readings than a fixed confidence-threshold baseline?

One **row** = one region (cropped handwritten math line + recogniser LaTeX). Label = `needs_correction` after LaTeX normalisation.

## Quick start

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m src.data_generator      # data/features.csv + data/splits.json

# open docs/index.html
```

## Results (held-out test groups)

| Model | PR-AUC | Δ vs baseline (95% CI) | Recall@30% |
|---|---|---|---|
| Confidence threshold | 0.715 | — | 35.9% |
| Logistic regression | 0.816 | +0.100 [−0.006, 0.190] | 42.4% |
| Random forest | 0.830 | +0.115 [−0.007, 0.186] | 41.3% |

Shuffled-label control ≈ 0.56 (near prevalence → no obvious leakage).  
Full table, error analysis, and interactive review-budget slider: **docs/index.html**.

## Design rules

- Split by student/writer group only  
- Forbidden features: reference text, marks, student ID, question ID  
- Test set touched only in `05_evaluate_test.py`  
- Primary metric: PR-AUC; report missed errors at fixed review rates
