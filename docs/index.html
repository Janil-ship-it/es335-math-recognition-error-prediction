Pipeline

What we did

  1. Define the unit: one cropped line + recogniser LaTeX; label = needs correction after normalisation.
  2. Build a development proxy with student-level groups and realistic feature–error links.
  3. Split by student group only; freeze splits.json before modelling.
  4. Train confidence baseline, logistic regression, random forest, and SVM with grouped CV.
  5. Evaluate once on held-out students with bootstrap CIs over groups.
  6. Ship an interactive review-budget lab driven by precomputed scores.

Key findings

  • Learned models improve PR-AUC and recall at fixed review budgets relative to a pure confidence threshold on this proxy.
  • With only six test students, the 95% bootstrap intervals for the gains still include zero — we report the uncertainty, not a definitive win.
  • Shuffled-label control scores near prevalence, which is consistent with no obvious leakage.
