1 The question

At the same review budget (20%, 30%, 50% of lines), does a learned flagger catch more true recognition errors than a fixed confidence threshold?

One row

One region = one cropped handwritten math line + the recogniser’s LaTeX. Label needs_correction = 1 if normalised LaTeX differs from the reference.

What we never use

Reference text, marks, student ID, question ID. Only image quality, token confidences, and structure counts.

8 Limitations and claims

  • Development data uses simulated degradation; not yet full course-script scans.
  • Six test groups → wide CIs; deltas vs baseline still include zero.
  • One recogniser profile; operating point may shift with TexTeller/UniMERNet.

Claim. On this setup, logistic and forest improve PR-AUC and error recall at fixed budgets vs confidence threshold, with student-level bootstrap uncertainty and a negative control near prevalence.
