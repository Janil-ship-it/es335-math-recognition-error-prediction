Which Handwritten Math Lines Can We Trust?

Predicting recognition errors to route student answers for review

ES 335 · Janil Jain & Manan Parmar · November 2026

Question Data Methods Results Review Budget Limitations Reproduce

1. Research question

Given a cropped image of one line of handwritten mathematics and the LaTeX produced by a pre-trained recogniser, can a small classifier predict whether that LaTeX contains an error better than a fixed confidence threshold, so that only risky lines need human review?

  • Unit: one region (cropped line + recogniser output)
  • Target: needs_correction = 1 if normalised LaTeX differs from reference
  • Allowed features: image quality, token confidences, structure counts
  • Forbidden: reference text, marks, student ID, question ID

2. Data

Plan A (course scripts) was not available. Development uses a statistically realistic proxy (690 regions, 28 groups). Error rate ≈ 60%. Split by student group before modelling.

3. Methods

Baseline: rank by mean/min token confidence. Models: L2 logistic regression; random forest. Validation: 5-fold grouped CV + one-SE rule; final score on held-out test groups with bootstrap CIs.

5. Interactive: review-budget slider

At equal review budgets the learned models catch more errors than the confidence baseline (see table).

6. Limitations

  • Development data is a proxy; methodology is ready for real Plan A scans.
  • Small test set (6 groups) → wide intervals.
  • One proxy recogniser behaviour only.
