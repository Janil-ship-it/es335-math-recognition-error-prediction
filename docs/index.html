Which handwritten math lines can we trust?

After a recogniser turns a student’s line into LaTeX, which lines are likely wrong; so a marker only reviews those? Every number below is from the held-out test groups. Move the controls and the metrics recompute.

1 The question

At the same review budget (20%, 30%, 50% of lines), does a learned flagger catch more true recognition errors than a fixed confidence threshold? A modest or negative result is acceptable.

One row

One region = one cropped handwritten math line + the recogniser’s LaTeX. Label needs_correction = 1 if normalised LaTeX differs from the reference.

What we never use

Reference text, marks, student ID, question ID. Only image quality, token confidences, and structure counts from the predicted LaTeX.

4 How we evaluated

Split

Grouped by student. 22 groups for train/CV, 6 held out. Test touched only once in 05_evaluate_test.py. Splits fixed in data/splits.json (seed 42) before modelling.

Metrics

Primary: PR-AUC. Operational: recall of true errors at 20/30/50% review. Residual SER. Paired bootstrap over test students (2000). Shuffled-label control ≈ 0.56.

7 Error analysis

At 30% review the baseline still misses ~64% of true errors; logistic misses ~58%.

Baseline Logistic Forest

Where the models help. Misses tend to be moderate-confidence lines with poor image quality or complex structure, exactly where non-confidence features matter. Residual SER after reviewing the top 30% falls from ~0.13 (baseline) to ~0.12 (logistic).

8 Limitations and claims

  • Proxy data. Not real course scans. We claim a working methodology and ranking gains under this recogniser behaviour, not operational accuracy on IITGN scripts until Plan A runs.
  • Small test set. Six groups → wide CIs; deltas vs baseline are not yet significant at 95%.
  • One recogniser profile. Real TexTeller / UniMERNet confidences may shift the operating point.
  • High base error rate. Stress-tests ranking; gains may shrink when recognition improves.

What we claim. On this setup, logistic and forest improve PR-AUC and error recall at fixed review budgets relative to a confidence threshold, with uncertainty quantified by student-level bootstrap, and with a negative control that does not look like leakage.
