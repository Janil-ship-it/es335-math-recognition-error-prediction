Reproduce the numbers

python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m src.data_generator      # data/features.csv + splits.json
python -m src.04_train_cv         # grouped CV (never touches test)
python -m src.05_evaluate_test    # single final test evaluation + site JSON
pytest tests/ -q
# open docs/index.html (or enable GitHub Pages on /docs)

Seed is fixed at 42. data/splits.json is written once and must not be regenerated after results exist.
