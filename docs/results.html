How to read the numbers

  • Development results (CV) are used only for model selection and hyper-parameter choice.
  • Test results are reported once, after models are frozen.
  • The 1-SE CV-selected model is Logistic regression; it is used for review decisions even if Random Forest has a higher test PR-AUC.
  • Shuffled-label control should lie near the positive-class prevalence.
