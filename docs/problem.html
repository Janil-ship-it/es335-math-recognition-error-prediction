Problem formulation

Research question. Can a learned error-prediction model identify more incorrect handwritten mathematical recognitions than a confidence-based baseline at the same human review budget?

Unit of analysis

One row is one rendered handwritten mathematical expression together with the recogniser output. Simulated scan degradation is recorded for analysis but never used as a model feature.

Target

After LaTeX normalisation, needs_correction is set from exact mismatch when usable, otherwise from SER above a development-calibrated threshold. Exact mismatch and severe error are not interchangeable.

Grouping

Groups are normalised expression labels. Writer IDs are unavailable, so writer-level leakage cannot be excluded.
