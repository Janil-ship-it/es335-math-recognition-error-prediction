Data sources

Plan A (preferred) — course scripts

Anonymised scans of handwritten answers shared by Prof. Bhatia, with checked reference answers and marks. Access and the exact sample were still to be agreed at the time of this build. Target: about 25–30 students and 500+ regions. One row is one region, so sample size is students × regions per student.

Raw scans stay private and are excluded by .gitignore. Nothing identifying a student is published.

Plan B (fallback & development) — public data

We use a development proxy whose feature–error relationships follow documented handwritten mathematical expression recognition (HMER) failure modes (blur, low contrast, complex structure raise error risk; high token confidence lowers it). When real scans arrive, the same code path is reused unchanged.

For public context we reference MathWriting (Gervais et al., arXiv:2404.10690, CC BY-NC-SA 4.0) — approximately 230 000 human-written and 400 000 synthetic handwritten expressions paired with LaTeX. It was written on touch screens and can be rendered to images with the authors’ code. Because a recogniser’s training data may overlap with public sets, we treat any public subset as a development benchmark, not as proof on course scripts.

Current submission uses the development proxy generated by python -m src.data_generator (seed 42). Feature–error links are synthetic but follow the failure modes above. Results therefore describe the method, not yet operational performance on IITGN course scripts.

Labelling protocol

  • Both team members transcribe the same subset of regions independently into normalised LaTeX.
  • Agreement is measured; differences are resolved by discussion before trusting the references.
  • The recogniser’s output is never copied into the reference.
  • Different LaTeX strings can mean the same thing, so we normalise spacing, bracket style and equivalent commands before comparing.

Quality checks

  • Blur, shadows and skew across scans; cropping errors.
  • Share of regions that contain an error (measured first in a pilot).
  • Error rate by student / group.
  • Distribution of each confidence feature for correct versus wrong regions.
