Synthetic development data ES 335 · IITGN
In short. Plan A (preferred) is anonymised course scripts — not in this repo. Current numbers use a seeded development proxy whose feature–error relationships follow documented HMER failure modes.

Plan A — course scripts

Anonymised scans with checked references. Raw scans stay private and are gitignored. Target scale: about 25–30 students and 500+ regions.

Plan B — development proxy

Generated by python -m src.data_generator (seed 42). Blur, low contrast, and complex structure raise error risk; high token confidence lowers it. Public context: MathWriting (Gervais et al., arXiv:2404.10690, CC BY-NC-SA 4.0).

Results describe the method on this proxy, not operational performance on IITGN course scripts.
