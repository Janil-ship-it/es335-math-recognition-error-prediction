Which Handwritten Math Lines Can We Trust?

Claims, limitations, and what we do not claim

ES 335 · IIT Gandhinagar · Janil Jain & Manan Parmar

What we claim

On this recogniser, this development proxy (and, when available, these course scans), and these feature definitions, a learned flagger can rank lines so that, at the same review budget, more true recognition errors are caught than by a fixed confidence threshold. All gains are reported with student-level bootstrap intervals.

What we do not claim

  • That results transfer to other recognisers, scanners, subjects, or assignment formats.
  • That digitisation alone makes grading correct.
  • Statistically stable superiority: with only six test students the Δ intervals still include zero.
  • Token or time savings, unless measured with logged settings (currently an estimate only).

Known limitations

  • Small test set — six student groups; wide confidence intervals.
  • Development proxy — current numbers come from a synthetic dataset whose error process follows documented HMER failure modes, not yet from IITGN course scripts.
  • One recogniser family — real TexTeller/UniMERNet inference is interfaced but not required for the proxy path; results are for the confidence and image features defined here.
  • Line detector is a prototype — horizontal projection; production use needs correction or a trained detector.
  • References — human transcriptions by the team; inter-annotator agreement should be reported when Plan A data arrives.

Blocked components

  • Real student scans (privacy; not in repository).
  • Full-weight HMER models (large download + GPU preferred).
  • Mark-agreement analysis (requires Plan A marks).
